# squire_journal

Site estático (abrir `index.html`) com as funcionalidades do jogo squire, capturas e o devlog dos prompts por dia.

- `data/features.js`: funcionalidades e lista de capturas (editar à mão; capturas em `img/`).
- `data/prompts.js`: gerado por `python3 tools/build_devlog.py` a partir de `vault/raw/squire/05-prompts.md` (só leitura). Prompts sem dia contam como 18 de Outubro.
